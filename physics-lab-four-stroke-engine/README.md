# 四冲程汽油发动机 · 物理实验室

双击 `dist/index.html`，用支持 WebGL 2 的浏览器打开即可离线使用。Three.js、三维几何、材质、粒子和样式均已嵌入该文件。

打开后会从整机外观进入剖面，依次演示吸气、压缩、做功和排气，再展示完整循环。随时可以退出演示或拖动模型进入自由观察。拖动旋转，滚轮或双指缩放。点击冲程名称从该冲程开始播放。点击“逐冲程”会播放至下一个止点并暂停。拖动时间轴会暂停在所选角度。空格切换播放与暂停。

## 开发与运行

使用 Node.js 20 或以上版本。在项目根目录执行：

```sh
npm ci
npm run build
npm start
```

打开终端显示的本地地址。修改源码后，重新构建并重启预览服务。

## 模型与教学假设

曲轴转角 θ 是机构的共同输入。曲柄半径 r = 0.9，连杆长度 L = 3。曲柄销坐标为 (r sin θ, r cos θ)，活塞销高度为 r cos θ + √(L² − r² sin² θ)。曲柄每转 360°，活塞完成一次往返。凸轮轴以曲轴一半转速旋转，完整配气循环为 720°。

配气与点火采用初中物理理想时序，省略点火提前角和气门重叠。蓝色、橙色与灰色分别示意新鲜混合气、燃烧膨胀和废气。动画按教学速度推进，气体效果表示流向和体积变化。

## 源文件

- `src/engine.js` — 发动机几何、曲柄连杆机构、凸轮与气门
- `src/effects.js` — 气流示踪、缸内气体、火花和燃烧效果
- `src/studio.js`、`src/annotations.js` — 灯光、镜头、轨道控制和部件标注
- `src/main.js` — 四冲程播放、教学导览、时间轴与状态显示
- `index.html`、`src/style.css` — 网页界面
